# Ragavendhiran S — Python Developer Portfolio

## Files
- `index.html` — responsive portfolio website
- `Ragavendhiran_S_Resume.docx` — resume linked from the website (included when available)

## Publish free using GitHub Pages
1. Create a **public** repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html` and `Ragavendhiran_S_Resume.docx` to the repository root.
3. Open **Settings → Pages** and publish from the `main` branch, root folder.
4. Visit `https://YOUR-GITHUB-USERNAME.github.io` after publishing finishes.

## Important
- Review the resume and public contact details before publishing.
- The website is a static portfolio; it does not guarantee recruiter responses.
- Keep project descriptions high-level and do not publish confidential company code or data.
- Update the resume file in the repository whenever you replace your resume.
